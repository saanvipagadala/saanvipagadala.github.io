# MarsWorm

Turning Martian dirt into something a plant can grow in.
A bioengineering project by Saanvi, 2026.

## → [saanvipagadala.github.io/MarsWorm](https://saanvipagadala.github.io/MarsWorm)

The whole project is written up there. **Start there.**

Mars has dirt, not soil. It has crushed rock with nothing alive in it and a
salt, perchlorate, that poisons what you plant. A colony has to grow its own
food, so it needs a way to make that dirt grow things. This project designs
one, then tests every design in a computer model, then writes down the
experiments a lab would run to prove it or break it.

## The versions

Each time a design was tested it changed, and more than one answer came out.
Each is strong in some ways and weak in others, so the site keeps every one,
side by side. Each version is a complete site of its own:

| | Version | What it is |
|---|---|---|
| 5 | [A plant on open Mars](https://saanvipagadala.github.io/MarsWorm/v5-a-plant-on-open-mars/) | Version 4's plant taken outside, with nothing built around it. A leaf on Mars boils rather than wilts, so the plant only works because it is cold. The newest, and the least finished. |
| 4 | [The bioengineered plant](https://saanvipagadala.github.io/MarsWorm/v4-the-bioengineered-plant/) | No soil made first. A plant given the one enzyme it is missing, growing straight in raw Martian dirt. |
| 3 | [Earth microbes, no plumbing](https://saanvipagadala.github.io/MarsWorm/v3-earth-microbes-no-plumbing/) | Ordinary Earth microbes working in the dirt itself, one of them adapted to carry the job the hardware used to do. |
| 2 | [Earth microbes at work](https://saanvipagadala.github.io/MarsWorm/v2-earth-microbes-at-work/) | Three ordinary bacteria, a box of worms and some plumbing, inside a Martian dome. No genetic changes. |
| 1 | [The bioengineered organism](https://saanvipagadala.github.io/MarsWorm/v1-bioengineered-organism/) | One organism designed from 37 real genes, to do an earthworm's job and survive Mars on its own. |

The versions fall into two halves. Versions 2 and 3 make soil with microbes
and then grow food in it. Versions 4 and 5 skip the soil and change the plant
instead.

## The experiments

Every version comes with experiments, written up as run sheets a lab could
follow. Most have a codebook and a dry-run report made from invented numbers,
so the shape of a finished run can be seen before there is a real one.
